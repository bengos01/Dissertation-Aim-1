# Dissertation Aim 1

Code, reproducible outputs, and the Quarto manuscript for Sofia Bengoa's first dissertation paper on temporal trends and inequities in age at case creation (diagnosis) of first-episode non-affective psychosis in Chile, 2005–2023.

## Source of truth

- **Notion:** workflow, research decisions, unresolved questions, and meeting notes
- **RStudio:** analysis and R Markdown workflows
- **Quarto:** official manuscript source
- **GitHub:** version history for code, manuscript source, and nonconfidential reproducible outputs
- **EndNote:** citation management; export the paper's references to `manuscript/references.bib`
- **Word:** rendered manuscript copies for review and submission, not a second independently edited master draft

The official manuscript source is `manuscript/aim1-manuscript.qmd`.

## Analysis files (run in order)

| File | Purpose | Status |
|:--|:--|:--|
| `01_Data_Exploration_QC.Rmd` | Record-level descriptive and quality-control review of the raw extract | Run on real data |
| `02_Repeated_Records_Review.Rmd` | Patterns among people with more than one record | Run on real data |
| `03_Cohort_Definitions_Comparison.Rmd` | Compares cohort Options A, B, and C | Run on real data; Option B chosen |
| `03a_Cohort B Definition Review.Rmd` | Option B attrition: exclusions by year and age | Ready to run |
| `03b_Proportions Among Registry Subpopulations.Rmd` | Share of people ever confirmed, by subgroup | Ready to run |
| `04_Aim1_Descriptives_and_Trends.Rmd` | Option B Table 1 and descriptive age trends | Date-reading fix on 2026-11-10; re-run on real data |

**Aim 1 cohort (Option B):** records with `ipd_cofirmado = SI` and `ipd_descartado = NO`; each person's earliest such record; then calendar years 2005–2023 and ages 15–65. Expected: 22,471 people before restrictions, 20,388 after.

Every Rmd rebuilds what it needs directly from the raw data rather than depending on objects created by another file. To run a file on the real data, update `data_file` (and `codebook_file`) in its import chunk.

## Repository contents

- `documentation/`: analysis decisions, data documentation, and reproducibility notes
- `manuscript/`: Quarto manuscript source and references
- `output/figures/`: reproducible figures
- `output/tables/`: reproducible tables
- `data/`: local-only data location; research data must not be committed

Rendered HTML files are treated as temporary local outputs and are excluded by `.gitignore`; they can be regenerated by knitting the corresponding R Markdown file.

## Data protection

Do not upload individual-level, identifiable, restricted, or sensitive research data to GitHub, even though this repository is private. The `.gitignore` excludes common data formats, the contents of local data folders, rendered HTML files, and other temporary/local files.

# Dissertation Aim 1

Code, reproducible outputs, and the Quarto manuscript for Sofia Bengoa's first dissertation paper on temporal trends and inequities in age at diagnosis/case creation of first-episode non-affective psychosis in Chile, 2005–2023.

## Source of truth

- **Notion:** workflow, research decisions, unresolved questions, and meeting notes
- **RStudio:** analysis and R Markdown workflows
- **Quarto:** official manuscript source
- **GitHub:** version history for code, manuscript source, and nonconfidential reproducible outputs
- **EndNote:** citation management; export the paper's references to `manuscript/references.bib`
- **Word:** rendered manuscript copies for review and submission, not a second independently edited master draft

The official manuscript source is `manuscript/aim1-manuscript.qmd`.

## Main analysis files

- `Descriptive_QC.Rmd`: first-pass descriptive and quality-control review of the raw registry data
- `Duplicates_Review.Rmd`: investigation of individuals with more than one registry record
- `Aim1_Analytic_Sample.Rmd`: construction and documentation of the final Aim 1 analytic cohort
- `Aim1_analysis.Rmd`: primary Aim 1 descriptive, temporal-trend, regression, and sensitivity analyses

These files serve different purposes. The main analysis file should ultimately reproduce the finalized analytic-sample rules directly from the raw data rather than depend on objects created by another R Markdown file.

## Repository contents

- `documentation/`: analysis decisions, data documentation, and reproducibility notes
- `manuscript/`: Quarto manuscript source and references
- `output/figures/`: reproducible figures
- `output/tables/`: reproducible tables
- `data/`: local-only data location; research data must not be committed

Rendered HTML files are treated as temporary local outputs and are excluded by `.gitignore`; they can be regenerated by knitting the corresponding R Markdown file.

## Current workflow

1. **Descriptive/QC review — completed.** The first-pass QC R Markdown has been run on the real restricted registry data.
2. **Duplicate-record review — in progress.** `Duplicates_Review.Rmd` has been developed and tested using synthetic data; review of the corresponding real-data output is needed before selecting a repeated-record rule.
3. **Analytic-sample construction — scaffolded.** Age 15–65 and calendar years 2005–2023 are established restrictions. Final FEP/NAPD eligibility and repeated-record rules remain to be finalized.
4. **Primary analysis — scaffolded.** `Aim1_analysis.Rmd` will reproduce the final cohort definition, create analysis variables, produce descriptive and temporal summaries, and implement the four planned regression steps.
5. **Manuscript — ongoing.** Update `manuscript/aim1-manuscript.qmd` as data definitions and analysis decisions are confirmed.

## Key pending decisions

## Data protection

Do not upload individual-level, identifiable, restricted, or sensitive research data to GitHub, even though this repository is private. The `.gitignore` excludes common data formats, the contents of local data folders, rendered HTML files, and other temporary/local files.
